📊 Comment le score est calculé

Le score d'une zone = la demande non satisfaite : le nombre d'adhérents potentiels que les salles déjà présentes ne captent pas encore.

Le calcul

Demande = population atteignable × 10 % × pouvoir d'achat
Offre = Σ ( surface des salles × 1,4 adhérent/m² )
Score = max( 0 , Demande − Offre )

Sur la carte : approximation pondérée par la distance. Au clic « zone 15 min » : calcul exact sur la zone réellement accessible en voiture. La couleur est mise à l'échelle log (pour que les villes moyennes ressortent) ; les chiffres affichés, eux, sont réels.

D'où viennent les données

🧍 Population & communes — INSEE (API geo.api.gouv.fr)
💶 Revenu médian — INSEE Filosofi (via OpenDataSoft)
🏋️ Salles de sport — OpenStreetMap (Overpass)
🚗 Temps de trajet (zone 15 min) — Valhalla / OpenStreetMap
🛣️ Flux domicile-travail (v2) — INSEE 2015 (via OpenDataSoft)
🚦 Trafic modélisé (v3) — navettes INSEE routées sur OpenStreetMap (OSRM, autoroutes exclues)
🗺️ Fond de carte — OpenStreetMap

Hypothèses

  • 10 % de la population est adhérente d'une salle (moyenne France, modulée par le revenu local).
  • 1,4 adhérent / m² de salle (fourchette métier 1,2–1,7 ; ≈ 2 500 adhérents pour 1 800 m²).
  • Salle cartographiée en polygone → surface mesurée. Salle en point → surface estimée selon le type (low-cost ~1 400 m², généraliste ~600, premium ~800, studio ~250).
  • Passage / flux (bouton « 🛣️ Flux », 3 modèles comparables) : v1 gravitaire (commune → pôle le plus proche, ligne droite) · v2 INSEE réel (vraies navettes domicile-travail 2015 >100 actifs, ligne droite) · v3 trafic modélisé = ces navettes routées sur les vraies routes (OSRM/OpenStreetMap), autoroutes exclues, départementales incluses — le plus réaliste ; routes affichées colorées selon le trafic. Limites v3 : navettes 2015 uniquement (hors loisir/commerces), itinéraire le plus rapide.
  • Les studios de yoga sont exclus (mais une salle généraliste proposant aussi du yoga est conservée).
⚠️ Les salles proviennent d'OpenStreetMap, qui peut être incomplet : si des salles manquent, une zone peut sembler plus favorable qu'en réalité. Vérifie la liste des salles sur le terrain avant de décider.

⚠️ Serveur local requis

Ce fichier doit être servi via un serveur HTTP local pour que les salles de sport puissent être chargées. Ouvrez un terminal dans ce dossier et lancez :

python -m http.server 8765

Puis ouvrez votre navigateur sur :

http://localhost:8765/gymlocator.html

Python est préinstallé sur Mac et Linux. Sur Windows, téléchargez-le sur python.org.
Ou double-cliquez sur lancer_windows.bat si vous êtes sur Windows.
